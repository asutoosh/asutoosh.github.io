PG Growth Websites

Real client demand generation and local-market impact.

  • 1) Upcmts.com - first SaaS attempt (failed but foundational)

    WordPress-based service for "first comment" use cases in giveaway ecosystems where timing mattered.

    • What happened: project eventually shut down (domain expired in Nov 2025).
    • Main lesson: distribution is often more important than building quality alone.

  • 2) Client websites - practical market impact

    • Kangaroo Housing: kangaroohousing.in for a Delhi PG owner, contributing to roughly 10-12 new clients monthly.
    • Swami Vivekanand PG: second property website for the same owner with continued iteration.
    • NGO build: delivered for a Delhi-based NGO (public details intentionally withheld).
    • Freya project: freyatrades.page + live demo with IP/browser restrictions, resulting in 50+ sales and around $5K revenue.

  • 3) Trading dashboard - product thinking phase

    dashboard.asutoosh.me is a 24/7 signal dashboard built after repeated trading-client engagements.

    • Scope: Forex + crypto signals in one place.
    • System baseline: around 40% win rate with 1:5 risk-reward framing.
    • Community: 40+ traders using the system daily.

  • 4) Smart Rewrite Keyboard (Android)

    Internal Play Store testing release built for practical writing assistance.

    • Core capabilities: rewrite sentences, translate, GPT-style assistant workflow.
    • Status: testing/internal access; built for learning and market validation.

  • 5) Current active build pipeline

    Auto blog poster (WordPress + SEO) Image enhancer API UGC ad content generator Whisper transcription pipeline Conscious Recall platform X bookmark manager

    Operating principle: launch fast, test quickly, scale only validated bets.

Most Important Build: Dupages

Dupages is positioned as a student accommodation platform connecting Delhi PG owners with incoming students. The mapping system currently covers 90+ Delhi University colleges with nearest-PG discovery logic around a 300-meter radius.

  • Why now: each year a large student cohort relocates and struggles with discovery friction.
  • Execution strategy: owner onboarding through calling agent and WhatsApp workflows, with app + SEO expansion.
  • Business intent: first project being pushed with full scale mindset and long-term monetization planning.
